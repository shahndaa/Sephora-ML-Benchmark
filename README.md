# Sephora-ML-Benchmark
Sephora ML Benchmark – Compares 8 algorithms (Linear Regression, Logistic Regression, Decision Tree, Random Forest, KNN, Naive Bayes, XGBoost, SVM) implemented from scratch (NumPy) vs. library versions (scikit-learn/XGBoost) on real Sephora review data. Full pipeline + interactive dashboard.
